# Project
Multi-Agent Research Assistant using AutoGen
In this project, I built a multi-agent research assistant that automates the process of discovering, analyzing, and summarizing academic papers. I integrated several AI agents that handle topic refinement, paper discovery, insight extraction, report compilation, and gap analysis, allowing for a structured research workflow. I worked with Python, API integrations, and agent orchestration to create a system capable of end-to-end research automation, including human-in-the-loop approval for enhanced control and oversight.

This is a fully functional research assistant that produces well-structured reports, highlighting key insights and future research directions.
